🔐 Google OAuth Setup Guide

⚠️ Important: You need to complete this setup to enable Gmail login functionality.

Step 1: Open Google Cloud Console

Click the button below to open the Google Cloud Console where you'll create your OAuth credentials.

🚀 Open Google Cloud Console

Step 2: Create or Select Project

  • Sign in with your Google account
  • Click the project dropdown at the top
  • Click "NEW PROJECT" or select existing project
  • Enter project name: "DEVFORGE Authentication"
  • Click "CREATE"

Step 3: Enable Required APIs

Go to "APIs & Services" → "Library" and enable:

  • Google Identity Services API
  • Google OAuth2 API
📚 Enable Identity Services API

Step 4: Configure OAuth Consent Screen

  • Go to "APIs & Services" → "OAuth consent screen"
  • Choose "External" and click "CREATE"
  • Fill in: App name "DEVFORGE", User support email
  • Add scopes: email, profile, openid
  • Click "SAVE AND CONTINUE" through all steps

Step 5: Create OAuth 2.0 Client ID

  • Go to "APIs & Services" → "Credentials"
  • Click "+ CREATE CREDENTIALS" → "OAuth 2.0 Client IDs"
  • Select "Web application"
  • Name: "DEVFORGE Web Client"
  • Add to "Authorized JavaScript origins":
http://localhost:4000 https://localhost:4000

Click "CREATE"

🔑 Create Credentials

Step 6: Copy Client ID

After creating the credentials, you'll see your Client ID. Copy it and update your configuration:

// In src/config/googleAuth.js CLIENT_ID: 'your-client-id-here.apps.googleusercontent.com'

Step 7: Test Your Setup

  • Save the configuration file
  • Restart your development server: npm run dev
  • Go to http://localhost:4000
  • Click "Login" → "Google"
  • Sign in with your Google account
🧪 Test Your App
💡 Pro Tip: Keep your Client ID secure and never commit it to public repositories. For production, consider using environment variables.
